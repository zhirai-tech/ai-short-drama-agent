# AI Short Drama Agent

A DeepSeek Harness plugin that packages six runtime agents, their orchestration and production-stage conventions from the ZHIRAI short-drama system.

## Contents
- Six runtime agent presets
- Director orchestration and named delegation tools
- Agent architecture documentation and prompt assets
- No model/provider declaration; the Harness selects the model
